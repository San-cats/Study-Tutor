# 踩坑记录（每一个坑都是学费）

## 拼写错误类（每个都让程序死过）

| 错误写法 | 正确写法 | 当时现象 |
|---------|---------|---------|
| `"context"` | `"content"` | API 不认字段 |
| `"descripiton"` | `"description"` | 工具说明失效 |
| `"sysytem"` | `"system"` | 人设失效，AI 行为不对 |
| `"utf_8"` | `"utf-8"` | 能用但非标准 |

**教训：API 字段名一个字母都不能错。报错时先逐字母核对拼写。**

## 结构错误类

| 错误 | 现象 | 修法 |
|------|------|------|
| `required` 写在 `properties` 里面 | API 400：`["path"] is not of types` | required 和 properties 平级 |
| `else` 挂在 for 上而不是 if 上 | 循环一轮就断，打印 None | 缩进对齐 if |
| 循环体里还用 `[0]` 不用循环变量 tc | 多次调用时重复处理第一次 | 循环体里用 tc |
| 内层 while 没有 break | 无限刷屏，API 费用燃烧 | Agent 循环的 else 分支必须 break |
| 文件末尾没有 `if __name__ == "__main__": main()` | 运行毫无反应 | 补上启动按钮 |
| 调用传 3 个参数，定义只收 2 个 | ValueError: not enough values to unpack | 参数按位置对号入座，不看变量名；改函数签名后核对所有调用点 |

**教训：嵌套结构的缩进 = 逻辑结构。改代码先看缩进对齐。**

## 概念混淆类

| 混淆 | 区别 |
|------|------|
| print vs return | print 显示给人看（返回 None）；return 交出值 |
| strip vs split | strip 剥空白（返回字符串）；split 劈列表 |
| 字符串比较 vs 数字比较 | "10" < "9"（字典序）；10 > 9 |
| `d[key]` vs `d.get(key, 默认)` | 前者键不存在就 KeyError；后者安全 |

## 逻辑错误类

| 错误 | 当时现象 |
|------|---------|
| 删文件判断反了（isdir 为真才删） | 删文件被拒绝，删文件夹报错 |
| `num[char]` 和 `char.lower()` 混用 | "Success" 大写 S 触发 KeyError |
| 工具执行后没把结果发回 AI 再问 | AI 只能瞎编，打印 None |
| 第二次请求不带 tools | AI 想调工具也调不了 |
| 工具函数忘 return | AI 收到 "None"，一脸懵 |

## 环境类

| 坑 | 解法 |
|----|------|
| 中文 Windows 控制台 GBK 报错/乱码 | 文件头 `# -*- coding: utf-8 -*-`；emoji 会炸，用 [OK]/[FAIL] 代替 |
| pip 装包超时/找不到 | 加清华镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| PowerShell 禁止运行脚本 | `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned` |
| PyCharm 解释器指错（Anaconda 抢） | Settings → Project → Python Interpreter 手动指向 venv |
| .env 找不到 | 路径层级数对（往上几层就 dirname 几次，或直接写死） |
| 路径带空格（F:\AI agent） | 命令行里加引号 `cd "F:\AI agent"` |
| .env / venv 被 git 跟踪 | 密钥和几千个库文件进了仓库 | 根目录建 .gitignore（.env、venv/、__pycache__/、.idea/），再 `git rm -r --cached .` + `git add .` 重新登记 |

## 安全类（职业铁律）

**密钥一旦进过 git 历史，就当它已经泄露。** commit 是永久档案，删文件也删不掉历史。仓库 push 到 GitHub 之前，先去平台把 key 重新生成一个（换锁）。密钥 = 银行卡密码：不进代码、不进截图、只进 .env。

## 调试心法

1. **探针打印**：不确定哪里错，就在关键位置 print 看实际值
2. **先翻译报错最后一行**：英文报错最后一行是核心信息
3. **跑起来验证，别用眼睛看代码**：AI 有没有真调工具，看探针打印几次
4. **小步测试**：写完一个函数就测，别等全写完
